GitHub Pages setup:
1. Create or open a repository.
2. Upload index.html and the assets folder, preserving the folder structure.
3. In Settings > Pages, deploy from your main branch / root.
4. The page will load the embedded video from assets/ABI_1min_video.mp4.

No external libraries or web fonts are required.
